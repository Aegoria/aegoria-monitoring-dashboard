# Cybersecurity Monitoring Platform — Group 3

## Overview

This repository contains the **Group 3 implementation** of the cybersecurity monitoring platform developed during the hackathon.

Group 3 is responsible for the **user-facing platform and data infrastructure**, which allows users to visualize system activity, security alerts, and device information collected by the monitoring system.

The platform provides a **web dashboard and backend services** that interact with a centralized database to display logs and alerts generated by the cybersecurity analysis system.

This repository includes:

* Web dashboard (frontend)
* Dashboard backend API
* Database schema and setup files

Other system components such as the **endpoint agent, log processing server, and AI detection models** are implemented by other groups.

---

# System Responsibilities (Group 3)

Group 3 focuses on building the platform layer that allows users to interact with the monitoring system.

Responsibilities include:

* Dashboard frontend
* Dashboard backend API
* Centralized log database
* Visualization tools for logs and alerts

The dashboard allows users to:

* View registered users and machines
* Explore system audit logs
* Monitor security alerts

# Backend (Dashboard API)

The backend API provides endpoints used by the frontend dashboard.

Responsibilities:

* Retrieve audit logs from the database
* Retrieve alerts generated by the detection system
* Retrieve user information
* Retrieve reports
* Provide dashboard summary statistics

API endpoints are defined in `backend/swagger-help.yaml`.

You can copy/paste the contents of the YAML file into:

https://editor.swagger.io/

to explore and test the API documentation.

# Database

The database stores all monitoring platform data.

Database engine:

**PostgreSQL**

Database setup files are located in:
```
database/schema.sql
database/seed_data.sql
```

The schema is designed to store system activity, alerts generated by detection models, and generated reports.

---

# Database Schema

## Users

Stores registered users of the monitoring platform.

| Field | Description |
|------|-------------|
| id | Primary key |
| username | User's display name |
| email | User email |
| role | User role (admin, analyst, etc.) |
| created_at | Account creation timestamp |

---

## Audit Logs

Stores system events collected from monitored machines.

| Field | Description |
|------|-------------|
| id | Primary key |
| user_id | Associated user |
| machine_id | Identifier of the monitored machine |
| event_type | Type of system event |
| event_message | Event description |
| event_time | Timestamp of the event |
| severity | Event severity level |

Relationships:

* `user_id → users.id`

---

## Alerts

Stores anomalies detected by the AI detection system.

| Field | Description |
|------|-------------|
| id | Primary key |
| audit_id | Related audit log event |
| anomaly_score | Score produced by detection model |
| alert_type | Type of security alert |
| description | Detailed explanation |
| created_at | Alert creation timestamp |

Relationships:

* `audit_id → audit_logs.id`

Alerts are generated from suspicious or anomalous **audit log events**.

---

## Reports

Stores generated security reports and summaries.

| Field | Description |
|------|-------------|
| id | Primary key |
| report_name | Name of the report |
| generated_at | Report generation timestamp |
| status | Status of the report |
| summary | Report summary |

Reports may include aggregated statistics about logs, alerts, and system activity.

# Setup Instructions

## 1. Clone Repository
```
git clone https://github.com/your-repo/group3-platform.git
cd group3-platform
```
---

# 2. Database Setup

Create the PostgreSQL database and run the schema and seed scripts:
```
database/schema.sql
database/seed_data.sql
```
---

# 3. Backend Setup

```
cd backend
npm install
npm run dev
```

Server runs on: ```http://localhost:3000/```

--- 

# 4. Frontend Setup

```
npm create vite@latest frontend -- --template react
cd frontend
npm install
npm install -D tailwindcss postcss autoprefixer
npm install -D @tailwindcss/vite tailwindcss
npm install axios moment
npm install react-router-dom
npm run dev
```
Dashboard runs on: ````http://localhost:5173/```

# Cybersecurity Monitoring Platform — Group 3

## Overview

This repository contains the **Group 3 implementation** of the cybersecurity monitoring platform developed during the hackathon.

Group 3 is responsible for the **user-facing platform and data infrastructure**, which allows users to visualize system activity, security alerts, and device information collected by the monitoring system.

The platform provides a **web dashboard and backend services** that interact with a centralized database to display logs and alerts generated by the cybersecurity analysis system.

This repository includes:

* Web dashboard (frontend)
* Dashboard backend API
* Database schema and setup files

Other system components such as the **endpoint agent, log processing server, and AI detection models** are implemented by other groups.

---

# System Responsibilities (Group 3)

Group 3 focuses on building the platform layer that allows users to interact with the monitoring system.

Responsibilities include:

* Dashboard frontend
* Dashboard backend API
* Centralized log database
* Visualization tools for logs and alerts

The dashboard allows users to:

* View registered devices
* Explore system logs

# Frontend (Dashboard)

The frontend provides a **web interface** where users can monitor their systems and security alerts.

Built with:

* React (or Next.js)
* Modern component-based architecture
* API integration with backend services

### Main Pages

* **Dashboard**

  * System summary
  * Activity overview
  * Alert statistics

* **Devices**

  * List of registered machines

* **Logs**

  * View system log events
  * Filter by device or event type

* **Alerts**

  * Display detected security anomalies
  * View severity levels and alert details

---

# Backend (Dashboard API)

The backend API provides endpoints used by the frontend dashboard.

Responsibilities:

* Retrieve logs from the database
* Retrieve alerts
* Retrieve device information
* Provide dashboard summary statistics

Example API endpoints:

```
GET /devices
GET /logs
GET /alerts
GET /dashboard/summary
```

Future improvements include:

```
GET /logs?device_id=
GET /logs?event_type=
GET /alerts?severity=
GET /alerts?status=
```

# Database

The database stores all platform data including:

* users
* registered devices
* system logs
* generated alerts

Example schema entities:

### Users

Stores registered users of the platform.

### Devices

Machines connected to the monitoring platform.

### Logs

System events collected from endpoint agents.

### Alerts

Security alerts generated by the AI detection system.

# Setup Instructions

## 1. Clone Repository

```
git clone https://github.com/your-repo/group3-platform.git
cd group3-platform
```

---

## 2. Database Setup

Create the PostgreSQL database and run:

```
database/schema.sql
database/seed.sql
```

---

## 3. Backend Setup

```
cd backend
npm install
npm run dev
```

Server runs on:

```
http://localhost:3000
```

---

## 4. Frontend Setup

```
cd frontend
npm install
npm run dev
```

Dashboard runs on:

```
http://localhost:5173
```

# Cybersecurity Monitoring Platform — Group 3

## Overview

This repository contains the **Group 3 implementation** of the cybersecurity monitoring platform developed during the hackathon.

Group 3 is responsible for the **user-facing platform and data infrastructure**, which allows users to visualize system activity, security alerts, and device information collected by the monitoring system.

The platform provides a **web dashboard and backend services** that interact with a centralized database to display logs and alerts generated by the cybersecurity analysis system.

This repository includes:

* Web dashboard (frontend)
* Dashboard backend API
* Database schema and setup files

Other system components such as the **endpoint agent, log processing server, and AI detection models** are implemented by other groups.

# Backend (Dashboard API)

The backend API provides endpoints used by the frontend dashboard.

Responsibilities:

* Retrieve logs from the database

# Install instructions

1. Install **PostGreSQL**, and follow the install instructions.
2. Create a database on **pgAdmin** and name it *(example: "monitoring_db")*.
3. Copy/Paste the content of ```database/schema.sql``` into **PostGre's Query tool**, then **run script**.
4. *(optional)* Create a ```.env``` file in ```backend/```with all the values you need.
### Base values
```
# PostGre 
DB_USER=postgres
DB_PASSWORD=postgres
DB_NAME=monitoring_db
DB_HOST=localhost
DB_PORT=5432
```
**Creating an .env will be necessary if you need to put different values. Otherwise the program will default to these.**
5. Open terminals and type ```npm install``` on both **./frontend** and **./backend**.
6. Once the additional node packages have been installed, type ```npm run dev``` in the 2 mentionned folders.
7. If everything has been setted up correctly, you should get somehing like:
  * on ```frontend>```:
  ```
  VITE v7.3.1  ready in 806 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
  ```
  * on ```backend>```:
  ```
  Server running on port 3000
  Connected to PostgreSQL database 'monitoring_db'
  ```
  *NOTE: 5173 and 3000 are the default ports on localhost for respectively frontend and backend. To be modified.*

# Setup Instructions

## 1. Clone Repository

```
git clone https://github.com/your-repo/group3-platform.git
cd group3-platform
```

---

## 2. Database Setup

Create the PostgreSQL database and run:

```
database/schema.sql
database/seed.sql
```

---

## 3. Backend Setup

```
cd backend
npm install
npm run dev
```

Server runs on:

```
http://localhost:3000
```

---

## 4. Frontend Setup

```
npm create vite@latest frontend -- --template react
cd frontend
npm install
npm install -D tailwindcss postcss autoprefixer
npm install -D @tailwindcss/vite tailwindcss
npm install axios moment
npm install react-router-dom
npm run dev
```

Dashboard runs on:

```
http://localhost:5173
```
